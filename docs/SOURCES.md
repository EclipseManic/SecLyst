# Imported Sources And Provenance

Seclyst was assembled from the following sibling directories in the Combined Project workspace:

| Seclyst path | Source directory | Treatment |
| --- | --- | --- |
| `apps/web/` | `secconflux/` | Shell retained, renamed, connected to live engines, fixture tool reimplementations removed |
| `engines/malware/` | `Malware Analyzer/` | Production source, tests, rules, and original UI copied |
| `engines/ioc/` | `ioc-platform/` | Backend, tests, and original React UI copied |
| `engines/events/` | `Event-Analyzer/` | Production source, tests, Sigma data, and original UI copied |
| `engines/phishing/` | `Phishing-Mail-Detector/` | Production source, tests, and original UI copied; captured email samples excluded |
| `engines/ruleforge/` | `RuleForge/` | Engine, corpus, tests, and original UI copied from its separate repository |

## Excluded Material

The copy intentionally excludes Git metadata, Kilo worktrees, virtual environments, `node_modules`, build outputs, caches, databases, journals, `.env` files, logs, transcripts, screenshots generated by verification, captured API payloads, scratch scripts, and phishing sample emails.

## Original Integrity

`docs/source-baseline.json` records SHA-256 hashes for source files outside `Seclyst/`. Run `python scripts/source_snapshot.py` from this workspace to verify that implementation work did not alter those sources.

## License Status

The IOC platform includes its existing MIT license file. Several other imported source directories do not currently include a license grant. Seclyst does not invent or replace those terms. Confirm ownership and redistribution permissions before making this combined workspace public, and add a top-level license only when the correct terms are known.

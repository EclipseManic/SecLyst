# Gallery

Screenshots of each engine's own interface, kept in one place so they can be
browsed without digging through five engine directories.

These are captures of the **original tools as they were before they were brought
into Seclyst**. They document what each engine can do and where its screens came
from. For captures of the current unified workbench, see
[`../screenshots/`](../screenshots/).

## Adding images

Put them under the engine's folder and add a row to its table. Keep the original
filename where it came from a tool's own repository so provenance stays traceable.
